# http-server-rs 🚀

A high-performance, multithreaded HTTP/1.1 server built entirely from scratch in **Rust** using only the standard library (`std`). 

## 🛠️ Features
* Built with pure Rust standard libraries (`std::net`, `std::io`).
* Multithreaded connection handling (`std::thread`) to serve multiple clients simultaneously.
* Zero external framework dependencies (No Axum, No Hyper).
* Clean and modular systems-level code structure.
